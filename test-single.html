Single Dial Menu Test

How to Use:

  • Single Click: Opens/closes the dial menu
  • Double Click: Enables slide mode (FAB border turns red)
  • Drag (in slide mode): Move the FAB vertically
  • Drag icons: Rotate the dial to select items

This page has only ONE dial menu instance, so you can test the slide functionality without seeing "duplicate" FABs from overlapping instances.
